账号隐私说明

版本：2026-11-01.1

本页用于注册和管理 Bifrost 网关账号。新账号使用邮箱地址作为登录名，原用户名账号仍可登录。不收集微信密码、身份证号、手机号码或通讯录，也不通过本页读取微信身份。

注册时只检查邮箱格式和域名的 DNS 收信配置；DNS 查询涉及域名，不发送邮箱完整地址、验证邮件或验证码，不连接邮件服务器探测具体邮箱。通过检查不能证明具体邮箱存在、能够收信或属于本人，邮箱始终标记为未验证，不能据此自动找回密码或合并账号。登录名不区分大小写，保留点和加号后缀。

服务端保存登录名（新账号为邮箱）、域名检查方式和时间、随机账号编号、加盐的密码校验摘要、账号状态、创建及同意时间、密钥摘要、登录有效期和请求频率设置。密码不能从摘要取回；API key 保存校验摘要和经过认证加密的副本，用于本人登录后主动查看或复制；账号库不保存其明文。加密主密钥由服务器操作系统的凭据保护机制保存。旧版只含摘要的 Key，在其下一次通过 API 验证时补存加密副本，不改变原 Key 或权限。

登录状态通过安全 Cookie 保存，页面脚本不能读取该 Cookie。页面默认隐藏 API key，只有本人主动查看或复制时才读取。切换到后台或离开页面后清除页面中的原文；再次登录后仍可主动查看。不将 Key 写入浏览器本地存储。

你可以退出登录、停用 API key 或注销账号。注销将删除登录及密钥记录并拒绝旧凭证的新请求；已经开始的模型请求可能继续完成。统一账号模式保存按随机账号编号关联的 Token 用量、配额、预留及余额账目，供本人和管理员核对；这些计费凭证在注销后仍保留用于对账，不包含模型对话正文。

模型调用及上游渠道的数据处理应以运营方公布的服务与隐私说明为准。请求频率限制不代表 Token 或费用配额。需要帮助或忘记密码时，请联系向你提供邀请码的网关管理员。
