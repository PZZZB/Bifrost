账号隐私说明

版本：2026-10-25

本页用于注册和管理 Bifrost 网关账号。用户名仅作为账号标识；不收集微信密码、身份证号、手机号码或通讯录，也不通过本页读取微信身份。

服务端保存用户名、随机账号编号、加盐的密码校验摘要、账号状态、创建及同意时间、密钥摘要、登录有效期和请求频率设置。密码不能从摘要取回；API key 只在生成时返回明文，不在账号库中保存明文。

登录状态通过安全 Cookie 保存，页面脚本不能读取该 Cookie。页面只在当前窗口临时展示新 API key；切换到后台或离开页面后清除，不写入浏览器的本地存储。

你可以退出登录、停用 API key 或注销账号。注销将删除账号记录并拒绝旧凭证的新请求；已经开始的模型请求可能继续完成。

模型调用及上游渠道的数据处理应以运营方公布的服务与隐私说明为准。请求频率限制不代表 Token 或费用配额。需要帮助或忘记密码时，请联系向你提供邀请码的网关管理员。
