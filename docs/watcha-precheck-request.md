## 平台回复核对（2026-11-03）

- 平台表示支持个人申请收款；按已说明的模式，技术上可采用“额度包”。这不是 Claude 等上游模型的对外商用授权，也不能替代支付宝对签约、材料和商品的审核。
- 平台给出的当前合计手续费是 **1%（含支付宝及即刻收手续费）**，实时到账绑定的支付宝账户，并明确以签约协议和实际账单为准。初期日限额通常在 T+1 解除，实际金额和时间仍由支付宝决定。当前未核对本账号的协议、账单及全部收费项目，不能据此保证无其他费用或已解除限额。
- 用户付款后不回网页，服务端可以使用同一用户 ID 和权益 ID 调用 `access` 查询；外部积分核销重试须复用原幂等键及参数。本地账本也要防止重复入账，并能恢复“外部已扣减、本地未入账”的中断。这与已有沙箱恢复验证方向一致，不代表正式付款已经验收。
- 平台建议在绑定支付宝账户查看订单及相关通知，未提供可用于自动对账的订单／退款接口说明。积分交付后的退款规则、幂等结果保留期限、查询及核销频率仍未答明，不能自行补出回调、查询频率或退款策略。
- 平台明确不提供代办税务申报；报送、代扣代缴和可提供凭证还需进一步核实。不代办申报不能解释为没有报送或扣缴安排。
