# 受管 Claude 的用量与能力证据

账号池将上游订阅用量和本站用户人民币余额分别展示。订阅用量从虚拟机内已登录的官方 Claude SDK 读取，沿用现有 VPS 出口。只提取订阅类型、明确返回的用量窗口百分比及重置时间，不读取会话成本来推算余额，不导出登录凭据或账号身份。

当前锁定 SDK 的用量方法属于实验接口。调用前检查方法是否存在；失败、超时、未知值或超过十分钟的数据显示“暂不可读取”，真实返回的 0% 则保留。模型目录约每分钟刷新，用量查询约每五分钟一次，管理页约每十五秒取得本机快照。用量查询失败不会移除模型。管理员可在账号池查看各窗口重置时间，界面统一标明北京时间。

模型能力按证据分别显示：

- 图片和客户端工具：适配器已具备相应协议转换能力；目录未声明模型能力时，不据此把模型本身标成已实测。
- 思考档位：使用当前账号官方 SDK 目录明确返回的声明，保留其与真实调用的区别。
- 上下文：在不提交推理提示的空会话中选择目录中的模型，读取官方 CLI 当前预算。仅当返回的实际模型与该目录条目的 resolvedModel 完全匹配时采用，不能把别名回退后的预算套给其他模型。该数值不是满窗口压力测试结果，客户端仍可保留更小预算。
- 缓存：按实际响应的缓存读取 token 计量。不会用“模型支持缓存”保证某次请求命中。
- 调用验证：用户入口在账本完成持久结算后记录正常结束的成功回复。工具待回传、截断、错误、中断、缺少可靠用量或没有有效文本的回复不能记为通过。记录可包含已观察到的图片请求、工具结果回传或缓存命中，但不保存提示、图片、工具参数或输出。

验证记录绑定虚拟机内派生的账号版本：使用私有中继密钥对账号标识做 HMAC，仅版本摘要经过私有健康接口。更换账号或目录能力变化会使旧验证失效。与现有其他渠道一致，调用验证为当前进程内的观察记录，重启后通过后续真实调用重新建立；不存在记录时不能声称调用失败。正常刷新页面不会清除验证。

这些元数据沿用受认证保护的私有 `/health` 和模型目录路径，不增加公网管理接口。修改账号池展示、刷新元数据及记录调用证据都不增加用户余额、不变更现有 Key、开放模型或虚拟机网络边界，也不启用收款。
