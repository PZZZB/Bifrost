## 微信、支付宝直接申请的实际边界

- 微信普通服务商的小微进件产品介绍明确限定部分行业，并写明不支持通过该通道签约线上虚拟行业。接口参数中存在“线上商品/服务交易”，基础支付权限表中存在 JSAPI/Native，都不能单独证明模型 API 服务符合进件要求。平台收付通是另一种平台商户方案，不能直接套到自建个人网站。
- 本次经本人扫码登录支付宝后，实际打开当面付申请表：营业执照标注“可选”，交易场景为“线下场所”，要求真实店铺信息、招牌照片、地址、联系人和短信验证。没有提交申请或上传资料。个人能申请部分当面付，不等于已经获准在 Bifrost 网页销售 API 额度。
- 支付宝公开帮助页面对当面付个人账户与电脑/手机网站支付分别列出条件，不能混为同一种资格。网页介绍和实际表单也存在细节差异，应以实际签约产品和审核结论为准。

来源：[微信小微产品介绍](https://pay.wechatpay.cn/doc/v3/partner/4012165168)、[微信小微申请参数](https://pay.wechatpay.cn/doc/v3/partner/4012722249)、[支付宝公开规则](https://help.alipay.com/enterprise/knowledgeDetail.htm?knowledgeId=201602191944)、[支付宝产品中心](https://b.alipay.com/page/product-workspace/all-product)。
