## 已核对的入口

- [支付宝 Vibe Pay 产品页](https://aipay.alipay.com/products/vibe-pay) 列出观猹为合作平台，并提供独立开发者定向开放申请入口。独立入口是 [意向留资](https://aipay.alipay.com/vibe-pay-intent/creator)，不等于自动获批商户。
- [支付宝套件文档](https://aipay.alipay.com/docs/vibe-pay/nowpay/nowpay-intro.html) 列明支持支付宝个人账号、积分包及合作平台接入。产品页和文档对独立接入开放进度存在差异，本次先试明确列出的合作平台。
- [爱猹收官网](https://pay.watcha.cn/) 的“进入控制台”链接进入观猹账号登录。其 [公开接入指引](https://pay.watcha.cn/agent.md) 区分沙箱和正式环境，提供自有应用、稳定用户标识与额度权益接口。

这条试用先验证支付宝渠道。微信支付仍需单独确认可用通道与业务资格，不能把微信扫码登录视为微信收款开通。

## 与现有余额的接入问题

公开指引主要提供权益检查 `POST /v1/entitlements/access`、购买入口及幂等核销 `POST /v1/entitlements/consume`。`user_id` 应取 Bifrost 服务端会话的稳定账号主键。额度包对应整数积分，核销使用固定 `idempotency_key`；鉴权凭据和沙箱、正式资源分别管理。

当前指引尚不足以提供既有 `PaymentTopups` 所需的完整支付订单、金额、交易号和退款凭证。本次验证了另一种原型：以成功的幂等积分核销作为服务额度交付的来源，在独立测试数据中调用现有 `ClientBilling.adjustBalance`。这是权益交付验证，不是支付订单或真实付款凭证。正式接入仍须确认业务准入、原支付订单／退款／对账能力与交付协议；不能虚构支付交易号复用旧适配器。

当前没有部署新的余额服务、运行时适配器或充值网页。原型使用现有 `ClientAccess`、`ClientBilling` 内核和私有隔离测试文件，没有操作生产账号或生产余额。用户正在调整的网页设计保持原状。

## 本次沙箱实测

- 沙箱商品配置为“模拟 1 元／100 测试积分”，不是正式报价；后台确认已上架、单位为积分。
- 使用真实 `ClientAccess` 内核创建两个隔离测试账号。购买前，付款测试账号为 `purchase_required`、0 积分；通过官方“确认模拟支付”后为 `granted`、100 积分。另一测试账号保持 0。
- 两个并发请求用同一个幂等键核销 10 积分，均返回成功，实际只扣 10。对剩余 90 积分请求核销 91，返回 `409 insufficient_quota`，余额保持 90。
- 使用第二个固定幂等键交付其余 90 积分后，当前余额为 0。重放第一笔操作仍返回原成功回执。回执中的余额是原操作快照，当前余额通过新的 `access` 查询确认。
- 先保存两笔核销回执，再在独立进程中向隔离 `ClientBilling` 测试账本交付相应服务额度。在“账本已提交、交付记录尚未确认”的边界停止脚本，重新打开账本、并发重放相同操作 UUID，最终仍只有 2 条入账记录、合计模拟 1 元，另一账号保持 0。

以上验证了原子核销和现有账本幂等能力能够支持恢复原型；没有实现或部署生产自动兑换任务、支付通知处理或退款适配器，也没有发生真实交易。资源映射、回执及运行时凭据保存在本机私有位置，凭据目录 0700、文件 0600。已配置的 Key 仅用于沙箱，不是全局 Agent 管理凭据。

## 沙箱验证顺序

1. 已完成本人登录，并核对没有既有应用后创建沙箱资源。
2. 已配置测试档位、保存受限服务端凭据，并完成上述原型验证。
3. 已在正常控制台流程开启正式配置权限，创建尚未配置价格的正式商品，选择“额度权益／积分”，取得官方配置二维码。该动作沿用本对话既有支付开通与替代平台试用授权，没有代理接受收款协议或费用条款，也没有把沙箱价格复制为正式价格。
4. 本人使用实际收款的支付宝核对账号、费率与协议，完成所需实名和签约；平台提示该商品绑定后不能更换收款账号。正式售价与上架需明确方案，生产消费及付款验证须与沙箱区分。平台首次签约需要支付宝审核，具体状态以后台实际查询为准。
5. 支付订单／退款／对账接口、税务处理及权益交付规则仍须明确；如需平台协助，复用备用草稿，经用户授权后提交。真实收款上线须完成业务与商户资格确认、生产适配和正式交易验收；不能用沙箱结果代替。当前没有实施任何真实付款，网站入口保持关闭。

## 费用与正式开通

支付宝套件文档列出 JSAPI 支付 0.6%～1%，另有即刻收商品经营费 0.4%。这是官方产品参考，尚未核实爱猹收是否另收服务费，也不是当前账号的实际报价。以实际开通协议及渠道结果确认完整费用，不按营销页“零门槛”承诺即时开通。

应用与积分包说明需要如实披露纯线上模型 API 服务、服务额度不转账不提现，以及仍待确认的模型商用授权。正式渠道审核、收款限额、商品上架和真实付款验收是不同条件。当前真实收款入口保持关闭。

平台账号、凭据、登录二维码和资源映射保存在本机私有记录，不进入仓库。公开指引作为接口资料使用，不覆盖用户授权与本项目账本要求。
